# 마지막 기술 설명 6문항 (연습용, 공식 문항 아님)

각 문항에 코드 위치 + 요구사항 ID + 체크포인트 SHA + 실제 검증 로그를 연결한다.
근거가 없으면 답을 지어내지 말고 미구현/미검증으로 표시한다. 1문항당 30~60초로 설명한다.

1. 실제 선택한 알고리즘/구조는 무엇이고 왜 선택했나? 고려한 대안, 이점, 코드에서 확인되는 한계는?
2. 실제 모듈별 책임과 호출 순서는? 변경한 파일·함수에서 어디를 확인할 수 있나?
3. 실제 입력 하나가 검증·가공·저장을 거쳐 출력되는 과정을 추적할 수 있나? 존재하지 않는 CSV/DB/Worker를 가정하지 않았나?
4. 잘못된 입력·경계값에서 실제로 어떻게 동작했나? 정상 경로와 비교한 테스트·로그는? 미실행 항목은?
5. 요구사항의 수치·규모·제약이 변하면 어느 모듈이 영향을 받나? 실제 측정한 지표와 아직 제안뿐인 테스트·개선안을 구분했나?
6. AI 협업 중 가장 큰 문제와 본인이 직접 해결한 문제는? AI 제안을 판단한 이유와 독립 검증 근거가 AI_COLLABORATION.md·코드·로그와 일치하나?
