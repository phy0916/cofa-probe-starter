# 변경 체크포인트 (초안)

근거: snapshot.json의 HEAD SHA·커밋 변경 파일·별도 미커밋 목록. 미커밋 내용은 해당 SHA에 포함되지 않는다.
모든 UNKNOWN은 확인 후 짧게 채운다. 근거가 없으면 UNKNOWN/미실행으로 유지한다.

- 요구사항 ID·원문 출처·수용 기준: UNKNOWN (work/requirements.csv 연결)
- 목적·의도 / 이전 동작 → 이후 동작: UNKNOWN
- 선택한 방법·이유 / 실제 고려한 대안·포기 이유: UNKNOWN
- 변경 파일·함수/모듈·책임: UNKNOWN (snapshot 파일 목록과 코드 위치 대조)
- 입력 → 검증·가공·상태 저장 → 출력 (실제 경로): UNKNOWN
- 실제 실행 명령·환경·결과·종료 코드·로그: UNKNOWN/미실행
- 로그의 실행 버전이 이 변경과 일치하는 근거: UNKNOWN
- 실패·예외·미구현·성능 한계 / 다음 확인: UNKNOWN
- AI가 제안·작성·수정한 부분과 확인 가능한 근거: UNKNOWN
- 본인이 직접 결정·수정·검증한 부분과 근거: UNKNOWN (본인 확인 필수)
- 최종 구현 커밋 SHA: UNKNOWN (미커밋 상태였다면 직접 커밋 후 새 체크포인트 생성)

전체 diff나 대화는 복사하지 않는다. 항목당 1~2줄과 파일/로그 참조만 적는다.
